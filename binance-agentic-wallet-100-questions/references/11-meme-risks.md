# Meme 币风险与貔貅识别

来源：S12（币安代币审计）+ U01（okx-sol-meme-agent 作者风控脚本），链接见 [资料索引](sources.md)。命令片段为路由提示，不是可直接执行的完整指令。本章把 meme 币特有风险（貔貅盘、rug pull、假聪明钱）沉淀成 agent 交易前的必查项和停止条件。

## Q101｜meme 币为什么比主流币更容易踩雷？

**性质：** 事实

**给 agent 的指令：** 把 meme 币当作「未审计、可被项目方随时改规则」的高风险资产处理。交易前必须走风险扫描，再单独核对「能不能卖出去」，不能用交易主流币的默认流程直接下单。

**边界 / 停止条件：** 热度、叙事、聪明钱买入都不能替代风险扫描；「别人都在买」不是安全证据。

## Q102｜什么是貔貅盘（honeypot）？

**性质：** 事实

**给 agent 的指令：** 貔貅盘 = 合约层面「只进不出」：你能买入，但卖出被合约拒绝或税率被设到接近 100%，钱进得去出不来。识别核心是「买入正常、卖出失败/异常」，问题出在合约代码，不是行情。

**边界 / 停止条件：** 卖出失败不能当成普通网络问题自动重试；发现疑似貔貅立即停止追加买入。

## Q103｜交易 meme 币前，风险扫描要拿哪些结论？

**性质：** 事实

**给 agent 的指令：** 至少核对：风险等级（LOW/MEDIUM/HIGH/CRITICAL/UNKNOWN）、mint 权限是否放弃、是否有冻结/黑名单、买卖税、流动性是否锁定、持有人集中度。逐项记录，任一命中高危项即停。

**边界 / 停止条件：** 只拿「价格、市值、热度」不算风险扫描；扫描结果不完整不得当作「已通过」。

## Q104｜风险扫描结果是 UNKNOWN 或接口不可用怎么办？

**性质：** 规则

**给 agent 的指令：** 把 UNKNOWN 当作「未知风险」处理，默认拦截（对应 okx-sol-meme-agent 的 blockUnknownRisk）。无人值守时一律暂停；要继续必须获得用户明确知情确认。

**边界 / 停止条件：** 不得把「没查到」解释成「没风险」；超时不能自动降级为安全。

## Q105｜风险等级 HIGH / CRITICAL 意味着什么？

**性质：** 事实

**给 agent 的指令：** HIGH 或 CRITICAL 直接拒绝入场；LOW/MEDIUM 仍需结合流动性、税率、集中度综合判断，不能只看等级通过就下单。

**边界 / 停止条件：** 不因「只买一点点」或「用户坚持」就绕过 HIGH/CRITICAL 拦截。

## Q106｜买入前为什么要先做一次「卖出方向」的报价验证？

**性质：** 规则

**给 agent 的指令：** 正式买入前，先做一次卖出方向的报价/预览，确认输出金额 > 0 且路径可用（对应 okx-sol-meme-agent 的 quoteLooksUsable）。能买不能卖的币，这一步会直接暴露。

**边界 / 停止条件：** 买入报价可用 ≠ 卖出可用；貔貅盘专坑只看买入的人。报价不可用就停止买入。

## Q107｜流动性、持有人、市值这些门槛该怎么定？

**性质：** 建议

**给 agent 的指令：** 在策略里设下限：最小流动性（如 10000U）、最小持有人（如 30）、市值区间，并单独设卖出滑点上限。低于门槛不入场。具体数值由用户填写，不默认。

**边界 / 停止条件：** 门槛是过滤不是保证；流动性可被临时注入又抽走（rug pull），不能只看下单那一刻的数值。

## Q108｜已经买入才发现是貔貅、卖不出去怎么办？

**性质：** 规则

**给 agent 的指令：** 停止追加、停止「摊低成本」；立即尝试按市价卖出并如实汇报结果；卖出失败则明确告知用户可能无法退出，不反复重试烧 gas，不承诺能回本。

**边界 / 停止条件：** 绝不为了回本继续加仓；止损归止损，救不回的仓位不硬救。

## Q109｜止损、分批止盈、回撤保护怎么写进规则？

**性质：** 建议

**给 agent 的指令：** 用三层退出（对应 okx-sol-meme-agent 的 exitRules）：硬止损（如 -50% 清仓）、分批止盈（如 +60% 卖 50%、+100% 卖 25%、+150% 卖 25%）、回撤保护（从高点回落 -35% 清仓）。参数由用户填进策略模板。

**边界 / 停止条件：** 止损不是保本承诺；流动性枯竭时止损可能无法按价成交。示例数值不冒充用户既有习惯。

## Q110｜聪明钱共振里，怎么排除「假信号 / 假聪明钱」？

**性质：** 建议

**给 agent 的指令：** 给监控地址做画像（对应 classifyWallet）：排除「高频交易菜鸡」（交易勤但胜率/盈利差）、「休眠地址」（长期无有效交易）、明显回撤+低胜率的地址；要求「同组共振」而非单个地址异动。

**边界 / 停止条件：** 聪明钱买入 ≠ 该币安全；诱多、自买自卖也能刷出假信号。信号只作证据，不直接成为下单授权。
